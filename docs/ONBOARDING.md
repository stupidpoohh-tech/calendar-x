# 시작 안내

GitHub의 tuto1.png부터 tuto5.png까지 순서대로 표시합니다. 현재 tuto1과 tuto4는 동일한 원본입니다.
상단의 단계 버튼으로 바로 이동할 수 있습니다. 이동만으로 완료 처리하지 않습니다.
원본 PNG는 변경하지 않습니다. SVG viewport로 팝업 본문만 잘라 표시하고 바깥 배경과 이미지 속 헤더·버튼은 제외합니다. 내비게이터·건너뛰기·이전·다음·숨김은 실제 HTML 컨트롤입니다.

## 표시 규칙

- 인증 상태를 확인한 뒤 처음 방문한 브라우저에서 자동으로 표시합니다.
- 완료(시작하기) 또는 다시 보지 않기를 선택하고 닫으면 이후 자동 표시하지 않습니다.
- 건너뛰기·Esc는 현재 탭의 세션 동안 숨깁니다. 새로고침은 숨김을 유지하고 새 세션에서는 다시 표시합니다.
- 로그인 계정과 로그아웃 데모의 기록은 분리합니다. 계정을 바꾸면 해당 계정의 기록을 사용합니다.
- 설정 → 사용 안내 → 튜토리얼 다시 보기로 1단계부터 열 수 있습니다. 기존 숨김 기록을 지우지 않습니다.
- 기록은 이 브라우저에만 저장됩니다. 다른 기기나 브라우저, 사이트 데이터 삭제 후에는 다시 표시될 수 있습니다.
- 저장소가 차단되어도 안내는 닫을 수 있습니다. 영구 숨김 저장 실패는 토스트로 알립니다.
- 초대 수락과 로그인 창을 우선합니다. 해당 흐름이 닫힌 뒤 안내를 표시합니다.

## 접근성·검증

모달의 이름/설명, 단계 정보, 제목 포커스, Tab/Shift+Tab 순환, Esc, 배경 inert,
스크롤 잠금, 닫은 뒤 포커스 복구를 제공합니다. 모바일은 화면 안에서 스크롤하며
단계 내비게이터와 하단 버튼은 유지하고 안내 본문·인포그래픽을 스크롤합니다.
원본 그림의 흰 배경과 색상을 유지합니다. 스크린 리더에는 단계별 제목과 설명을 별도로 제공합니다.

온보딩 상태·키보드 테스트: src/ui/onboarding.test.tsx.
기존 회귀 검증: npm run check 및 npm run build. 보안 규칙·저장 계층·금융 계산은 변경하지 않습니다.
