# 회복 항목 구분

- 설정 → 회복 → Recovery 옵션 관리와 회복 일정의 편집에서 끌 것(off) / 할 것(do)을 선택해 추가합니다.
- 기본 선택은 다음 회차에 복사됩니다. 이미 생성한 회차는 해당 일정을 열어 선택을 바꿉니다.
- 기존 데이터에 kind가 없으면 끌 것으로 읽습니다. 이름을 보고 자동 분류하거나 기존 항목을 다시 쓰지 않습니다.
- 이름과 분류는 회차마다 스냅샷으로 보존합니다. 기본 목록을 수정·삭제해도 지난 회복의 뜻이 바뀌지 않습니다.
- 중복 이름은 같은 구분 안에서만 막습니다. 분류 변경 시 같은 이름이 있으면 먼저 이름을 바꾸도록 알립니다.
- 백업 v12는 규칙과 회차의 분류를 보존합니다. v1~v11도 계속 읽으며, 구버전 앱은 v12를 거절해 분류를 버린 채 복원하지 않습니다.
- 회복 주기·완료·밀린 회복·일시중지 처리와 Firestore 보안 규칙은 변경하지 않았습니다.
