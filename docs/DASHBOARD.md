# 대시보드

내 공간의 기존 `all` 렌즈를 대시보드로 표시합니다. 저장된 렌즈 ID는 유지합니다.

- 오늘 남은 할 일, 앞으로 7일의 미완료 일정, 이번 달 노트 수를 요약합니다.
- 오늘부터 7일 중 날짜를 선택해 일정을 보고 기존 상세·완료·추가 기능을 사용합니다.
- 노트는 이번 달에 날짜가 있는 항목 중 최근 수정 순 3개를 표시합니다. 전체는 노트로 이동합니다.
- 생활비 외 가용은 가계부와 같은 원본 데이터 및 `headlineLimit` 계산을 사용합니다. 반복 전개 목록을 금액 계산에 넘기지 않습니다.
- 숨긴 노트·가계부는 대시보드에서도 숨깁니다. 조회 전·오류·빈 캐시에서는 수치와 빈 일정 안내를 확정하지 않습니다.
- 대시보드의 조회 창은 오늘 기준입니다. 캘린더에서 먼 달을 보다가 돌아와도 오늘을 조회합니다. 반복은 월말을 포함한 전체 7일에 펼칩니다.
- 개인 대시보드와 공유 데이터는 합치지 않습니다. 공유 공간은 기존 화면과 규칙을 유지합니다.

최상단은 로고 왼쪽 / 내 공간·같이 보기 오른쪽입니다. 공간 전환의 기존 노출·연결 규칙은 유지합니다.
