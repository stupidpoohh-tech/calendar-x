# 기기 저장과 계정 백업

- 로그인하지 않아도 일정, 노트, 가계부와 회복 설정을 사용할 수 있다. 비회원은 데모가 아닌 빈 개인 공간으로 시작한다.
- 기기 자료는 현재 사이트·브라우저의 IndexedDB에 저장한다. 새로고침해도 남지만 브라우저 데이터 삭제, 기기 분실에는 계정 백업이나 설정의 JSON 파일 백업이 필요하다. 앱을 처음 여는 데 필요한 파일의 오프라인 배포는 이번 변경에 포함하지 않는다.
- 로그인한 기존 사용자의 저장 경로와 공유 권한은 유지한다. 비회원 식별자는 Firebase에 보내지 않는다.
- 가입·로그인 후 기기 기록 배너에서 계정 백업을 실행한다. 이미 기록이 있는 계정에는 자동으로 합치지 않고 파일 백업·가져오기로 안내한다.
- 백업 중 기기 원본을 잠그고 대상 계정에 묶는다. 중단되면 같은 계정에서 다시 시도한다. 모든 기록과 설정의 서버 저장이 확인된 뒤에만 기기 작업 공간을 비우며, 이전 원본은 같은 기기 저장소에 보관한다. 로그아웃하면 별도의 빈 기기 공간으로 시작한다.
- 대시보드의 ‘며칠 버티나’는 현금흐름 카드와 동일한 오늘 기준 계산 함수를 사용한다. 조회 월이나 지출 합계로 대체하지 않는다.
- 터치 기기의 팝업 배경 이동을 제거하고 창 하나만 짧게 움직인다. 입력창 자동 포커스와 열림 애니메이션이 겹치지 않게 하고 달력 배치를 재사용한다. 실제 Galaxy 기기의 프레임 측정은 별도 확인이 필요하다.

검증: 기기 저장의 동시 쓰기·실패 원자성·재조회·계정 백업 재시도, 기존 계정 보호, 가계부 입력 회귀, 대시보드 금액/일수, Firestore 에뮬레이터 백업 왕복을 자동 테스트한다.
